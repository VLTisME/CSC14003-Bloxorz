# Stardew-Valley-Style Pixel Art UI Palette & Style Guide

## PALETTE (29 Colors)

### Neutrals (6)
- `ivory`: `#f2f0e5` - Light panel fill, parchment highlight, bright accents
- `silver`: `#b8b5b9` - Light grey border, disabled button highlight
- `grey_mid`: `#868188` - Medium grey, disabled button base
- `grey_dark`: `#646365` - Dark grey, disabled button shadow
- `slate`: `#45444f` - Slate blue-grey, dark neutral
- `ink`: `#212123` - Primary dark outline, high-contrast text, 1px logo outline

### Blues / Purples (9)
- `navy_1`: `#3a3858` - Night sky, dark background
- `plum_dark`: `#352b42` - Deep purple-black, text, logo bottom gradient fill
- `navy_2`: `#43436a` - Mid-tone night sky background
- `blue`: `#4b80ca` - Switch accent, water, interactive elements
- `sky`: `#68c2d3` - Bright water, goal highlight, star accent
- `mauve`: `#6a536e` - Dusk clouds, purple accent
- `dusk`: `#4b4158` - Shadow cloud, dark purple-grey outline for red/disabled buttons
- `grey_plum`: `#5f556a` - Muted purple-grey UI detail
- `orchid`: `#cf8acb` - Special star / gem accent

### Warm (8)
- `mint`: `#a2dcc7` - Soft pastel green-cyan accent
- `butter`: `#ede19e` - Gold/yellow star, orange button highlight
- `tan`: `#d3a068` - Warm wood highlight, logo 2px drop shadow
- `red`: `#b45252` - Red button base, danger / lose accent
- `brick`: `#80493a` - Dark reddish wood, logo top gradient fill, wood frame dark
- `wood`: `#a77b5b` - Natural carved wood, orange button shadow, frame mid
- `cream`: `#e5ceb4` - Parchment paper fill, main panel background
- `blush`: `#edc8c4` - Soft warm pink, red button highlight

### Greens (6)
- `lime`: `#c2d368` - Bright green button highlight
- `green`: `#8ab060` - Green button base, play/success accent
- `teal_dark`: `#567b79` - Green button shadow
- `moss`: `#4e584a` - Green button dark outline
- `olive_dark`: `#7b7243` - Deep olive shadow
- `sage`: `#b2b47e` - Soft light sage green

---

## Roles
- **Outlines / Text**: `ink` (`#212123`), `plum_dark` (`#352b42`)
- **Panel fill / Highlight**: `cream` (`#e5ceb4`), `ivory` (`#f2f0e5`)
- **Wood frame / Bevel**: `brick` (dark, `#80493a`), `wood` (mid, `#a77b5b`), `tan` (light, `#d3a068`)
- **Sky / Background**: `navy_1` (`#3a3858`), `navy_2` (`#43436a`), `plum_dark` (`#352b42`); Clouds: `mauve` (`#6a536e`), `dusk` (`#4b4158`)
- **Accents (Switches, water, stars)**: `blue` (`#4b80ca`), `sky` (`#68c2d3`), `butter` (`#ede19e`), `orchid` (`#cf8acb`)
- **Disabled**: `grey_dark` (`#646365`), `grey_mid` (`#868188`), `silver` (`#b8b5b9`)

---

## Button Ramps (4-Step: Dark Outline -> Shadow -> Base -> Highlight)
- **GREEN**: `#4e584a`, `#567b79`, `#8ab060`, `#c2d368` (moss, teal_dark, green, lime)
- **ORANGE**: `#80493a`, `#a77b5b`, `#d3a068`, `#ede19e` (brick, wood, tan, butter)
- **RED**: `#4b4158`, `#80493a`, `#b45252`, `#edc8c4` (dusk, brick, red, blush)
- **DISABLED**: `#4b4158`, `#646365`, `#868188`, `#b8b5b9` (dusk, grey_dark, grey_mid, silver)

---

## Logo Colors
- **1px Outline**: `ink` (`#212123`)
- **2px Drop Shadow**: `tan` (`#d3a068`)
- **Two-Tone Fill**: Top `brick` (`#80493a`), Bottom `plum_dark` (`#352b42`)
